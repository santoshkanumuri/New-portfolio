    Work

    Eight systems I've built for real teams. Open any one to see how it works, what it was tested against, and where it sits on the timeline.

    • AnswerASK_RAIDERTexas Tech's AI assistant for policies, dining and IT help.2025

      A conversational assistant for the whole university. It looks things up in operating policies, system regulations, dining services and the IT knowledge base, answers Tier-1 questions on its own, and routes the hard ones to a person. It grew out of a prototype I built in February 2025 with LangChain, Chroma and MCP integrations.

      How it works
      1. A question
      2. Retrieve from policies, dining and the IT knowledge base over MCP
      3. LLM answers from those sources
      4. Complex cases go to staff
      Tested against
      A projected 40% drop in IT Help Central tickets.
      Lineage
      Built with
      Python, FastAPI, ReactJS, LangChain, MCP, OpenAI / Llama / Ollama, Docker, Kubernetes, Helm
    • ReadPDF remediation serviceMakes scanned and digital PDFs work with screen readers, in-house.2025

      Public documents have to work for people who can't see them. This service runs OCR and language models over native and scanned PDFs in batches, with a self-service portal and a full audit log. It replaced outside vendors, Adobe Acrobat Services and AWS Textract, with something the university runs itself.

      How it works
      1. PDF, native or scanned
      2. OCR
      3. LLM rebuilds structure and tags
      4. Accessible PDF + audit log
      Tested against
      90% lower cost per document than the vendors it replaced, with more throughput.
      Lineage
      Built with
      Python, FastAPI, OCR models, LLMs, batch pipelines, PostgreSQL, Docker
    • AuditAccessibility audits & VPAT reportsWCAG 2.1 checks across 20+ university sites, with reports drafted by agents.2025

      Development teams run automated WCAG 2.1 audits across university web properties, see every finding in one dashboard, and generate VPAT reports with LLM agents. The models run in-house, so testing stays private and the university no longer pays an outside audit vendor.

      How it works
      1. A university website
      2. Automated WCAG 2.1 audit
      3. Central dashboard
      4. LLM agents draft the VPAT
      Tested against
      20+ digital properties, with no external audit vendor.
      Lineage
      Built with
      Python, AI agents, in-house model inference, WCAG 2.1, VPAT
    • CheckSyllabus compliance checkerReads every syllabus against state law and university policy.2025

      A language model reads each course syllabus, compares it with state legislative requirements and academic policy, flags what's missing with a suggested fix, and sends it through an approval workflow for the registrar's office. Less manual legal review, and one place to manage every syllabus.

      How it works
      1. A syllabus
      2. LLM compares it with state law and policy
      3. Flags with suggested fixes
      4. Approval workflow
      Tested against
      The registrar's syllabus review process.
      Lineage
      Built with
      Python, FastAPI, LLMs, workflow automation
    • LocateLive campus operations mapWhich printers, classroom AV, screens and dining spots are working, right now.2025

      Live feeds from ServiceNow ITSM, drawn on a map of campus: classroom AV systems, digital signage, networked printers and dining facilities. Facilities, IT and operations teams can find the nearest thing that works, and fix the broken ones sooner.

      How it works
      1. ServiceNow ITSM
      2. Live status feed
      3. Interactive campus map
      4. Nearest working resource
      Tested against
      Time to resolution for equipment and service issues across campus.

    • SeeArt similarity searchFinds artworks that look alike, and tracks what they sell for.2023–25

      Computer-vision embeddings for more than 35,000 artworks, stored in Pinecone, searchable by how they look and used to predict price trends. ETL pipelines bring in over 1,000 new works a month from three auction houses on a schedule, and email someone when a run fails.

      How it works
      1. Three auction houses
      2. Scheduled ETL
      3. Image embeddings
      4. Pinecone
      5. Similar works + price trends
      Tested against
      35,000+ artworks. 92% price-trend prediction accuracy. Retrieval 70% faster.
      Lineage
      Built with
      Python, PyTorch, Pinecone, AWS (Lambda, Step Functions, S3), MongoDB
    • SortResearch agents & a data warehouseReads websites and messy records so analysts don't have to.2023–25

      Three connected pieces. A local Llama 3.2 system that read more than 1,000 company websites and classified their research areas. A search agent that queries Google and DuckDuckGo and summarises results with GPT, with citations, running on AWS ECS with a CSV batch mode. And a warehouse that pulled 30,000+ Pitchbook records from five-plus sources into one place.

      How it works
      1. Websites, search APIs, Pitchbook
      2. Scrape and clean
      3. LLM classifies or summarises, with citations
      4. Warehouse
      5. Reports
      Tested against
      88% classification accuracy and 85% less manual sorting. 500+ rows an hour in batch mode. Market reports 45% faster.
      Lineage
      Built with
      Python, FastAPI, Llama 3.2, OpenAI, Gemini API, Docker, AWS ECS, DynamoDB
    • TrackLoan document tracking, at PwCKeeps track of every document behind a Citibank loan.2022–23

      On a 30-person team at PwC India, I led full-stack development of Citibank's internal loan document tracking system: Django microservices on Amazon Aurora (PostgreSQL), a React front end with role-based access, and everything in Docker so development, testing and production behaved the same. The work earned PwC's Digital Acumen Award.

      How it works
      1. Document request
      2. Django microservices
      3. Aurora PostgreSQL
      4. React UI with role-based access
      Tested against
      3,000+ requests a day at 99.8% uptime. Retrieval 65% faster. 85% fewer deployment errors.
      Lineage
      Built with
      Python, Django, ReactJS, PostgreSQL, Docker, AWS (EC2, S3, Lambda, Aurora)
